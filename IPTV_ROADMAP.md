# NeXus IPTV — Comprehensive Experience Roadmap

## Phase 1: Guest-Facing TV Interface (Foundation)
- [ ] TV-optimized guest UI (`/iptv/guest/[roomId]`)
- [ ] Personalized welcome screen with guest name, weather, stay info
- [ ] Channel grid with categories (news, sports, movies, kids, music)
- [ ] On-demand content browser (movies, series, hotel info)
- [ ] Language selector (EN, AR, FR, ES, DE, ZH)
- [ ] Large text / accessibility mode
- [ ] Remote-friendly navigation (D-pad support)

## Phase 2: In-Room Services (Revenue)
- [ ] Room service menu with categories + ordering
- [ ] Housekeeping requests (towels, cleaning, maintenance)
- [ ] Concierge requests (taxi, tour, restaurant booking)
- [ ] Spa & wellness booking
- [ ] Order status tracking
- [ ] Bill-to-room integration

## Phase 3: Guest Communication
- [ ] Hotel announcements / notifications on TV
- [ ] Staff-to-guest messaging
- [ ] Checkout reminder with express checkout
- [ ] Survey / feedback form
- [ ] Emergency information display

## Phase 4: Interactive Experience
- [ ] Local weather & forecast
- [ ] Flight status (if near airport)
- [ ] Local attractions with maps
- [ ] Hotel amenities guide (pool, gym, spa hours)
- [ ] Digital newspaper / magazines
- [ ] Screen mirroring / casting support

## Phase 5: Staff & Management
- [ ] Housekeeping TV dashboard (room status, cleaning queue)
- [ ] Maintenance alerts on TV
- [ ] Guest preference analytics
- [ ] Content performance (what guests watch)
- [ ] Premium content billing
